# Geo Meta Quiz

Тренажёр атрибутов стран для GeoGuessr по данным geohints.com.

Запуск: `python3 -m http.server 8765 -d docs`, затем открыть http://localhost:8765. Можно открыть и просто `docs/index.html`.

## Данные
- `docs/data.js` — индекс «страна → URL картинки» (около 2400 карточек, 5 категорий). Сами картинки подгружаются с CDN geohints.
- `tools/extract.py` — парсер сохранённых страниц `/meta/...`. Кладите HTML в папку как `<путь>.html` (`/` → `__`, например `signs__stop.html`), добавляйте категорию в `LABELS` и запускайте:
  `python3 -I tools/extract.py <папка> > docs/data.js`
- Логотипы, которые встречаются больше чем в одной стране, отбрасываются: по ним страну не определить.
